# experiment-log.md — R&D実験ログ（知財キャプチャーフォーマット）

**目的**: 実験の成功・失敗を「技術的背理法（Proof by Contradiction）」の形式で記録し、
特許出願の根拠・ノウハウの証拠・DDでの説明材料として機能させる。

**書き込みルール**: 実験終了後すぐに記録する。AIが `/moat-capture` 経由でIP Potentialを評価する。

**重要**: このファイルはLtV投資先専用のディープテック特化フォーマット。
バイオ・量子・素材・海洋・アグリテックなど全領域で使える汎用設計。
