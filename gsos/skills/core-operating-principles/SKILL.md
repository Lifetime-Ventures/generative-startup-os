The five non-negotiable principles for GSOS workflows are defined in the repository [CLAUDE.md, "Operating principles" section](../../../CLAUDE.md). Single source of truth.

Summary (full text in CLAUDE.md):

1. Never write OKRs from a blank page.
2. Yes/no over interrogation.
3. Founder-triggered, not automated.
4. Notion is the source of truth.
5. Pre-flight every skill.

When any /gsos command starts, re-read CLAUDE.md and apply these principles. Do not duplicate them here — that risks divergence.
