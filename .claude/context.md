# Generative Startup OS — 詳細コンテキスト

## 初回セットアップ手順

CLAUDE.mdの[COMPANY_NAME]が未置換の場合に以下を実行する：

日本語で一つずつ質問してください：

**Q1（会社・専門）：**
「あなたの会社名と、解決しようとしている技術的・科学的課題を一文で教えてください。
 例：量子センサーで医療診断の精度を10倍にする」

**Q2（Objective）：**
「今から3ヶ月後、どんな状態になっていれば成功と言えますか？
 例：プロトタイプが外部の研究機関に認められている状態」

**Q3（KR・数値化）：**
「その成功を測るために使える数字を1〜2個教えてください。
 例：検出感度が現在の100ppmから1ppmに改善している」

**Q4（禁止パターン）：**
「今まで失敗から学んだ、やってはいけないことを1〜2つ教えてください。
 例：顧客の要望を確認せず機能を追加する」

**Q5（今週）：**
「今週、最も時間をかけるべきことを一つだけ教えてください」

回答が揃ったら：
1. CLAUDE.mdの[プレースホルダー]を回答で更新することを提案
2. 本ファイル（context.md）のOKRセクションを更新することを提案
3. 承認後に両ファイルを更新
4. 「続けて /setup-mcp を実行しますか？」と聞く
