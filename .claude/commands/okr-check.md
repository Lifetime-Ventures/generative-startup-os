# /okr-check — OKRレビュー・L2分析
# Phase: 1以降
# 推奨実行タイミング: 月次（月末）・四半期末・weekly-roast前
# Last Updated: v5.0

---

## Purpose

NotionのOKR DBから取得した進捗データを受け取り、
「なぜ達成/未達なのか」「何を修正すべきか」をL2分析する。

**OKRは測定するためではなく、学習・修正するために使う。**

---

## When to Use

- 月次のレビュー前（KR進捗の確認）
- 四半期末の総括分析
- OKR Confidence Scoreが0.4以下の項目が出たとき
- /weekly-roast のインプット準備として

---

## Input

```
/okr-check [YYYY-QX]

以下をNotionのOKR DBからコピーして貼り付ける：

Objective: [目標文]

| KR# | Key Result | 目標値 | 現在値 | Confidence |
|-----|-----------|--------|--------|-----------|
| KR1 | [内容] | [目標] | [実績] | [0.X] |
| KR2 | [内容] | | | |

補足（任意）:
- 前月/前四半期のスコア:
- チームコメント:
- 外部環境の変化:
- 今期のPRR平均:
```

---

## Process

1. 各KRのConfidence Scoreを評価（0.7が理想ゾーン）
   - Confidence Score = (Current/Target) × min(1, PRR4週平均/0.75)
2. スコアが低いKRについて「仮説」「実行」「外部要因」のどれが原因かを分析
3. スコアが高すぎるKR（1.0）は目標設定が低すぎた可能性を指摘
4. OKR全体のObjectiveとKRの整合性を確認
5. 次月・次四半期のKR修正案を提示
6. PRRとの連動を分析（実行誠実性がConfidence Scoreに影響している箇所を特定）

## Confidence Score の判定基準

| スコア | 状態 | 推奨アクション |
|--------|------|--------------|
| > 0.7 | 🟢 順調 | 現状維持。目標が低すぎないか確認 |
| 0.4〜0.7 | 🟡 要注意 | PRR改善またはKR見直しを検討 |
| < 0.4 | 🔴 達成困難 | 目標値の見直しか、タスクの大幅増強が必要 |
| = 1.0 | ⚠️ 目標が低すぎる可能性 | 次期はより挑戦的な目標を設定 |

---

## Limitations

- OKRスコアの解釈は「良い/悪い」ではなく「学んでいるか」で判断する
- 「このOKRを達成すべきです」とは言わない
- Confidence Scoreの最終的な修正判断は創業者が行う
