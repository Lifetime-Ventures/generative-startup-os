# /team-prr — チームPRRダッシュボード

**発動コマンド**: `/team-prr`
**Phase**: 3（チーム 3-5名）

## 概要

N:Nのコミュニケーション環境で、チーム全体の実行誠実性を可視化する。
個人のPRRだけでなく、チーム全体の依存関係ボトルネックを検知する。

---

## 実行プロトコル

### 個人PRRの集計

```
各メンバーのPRRを計算:
  Member_i_PRR = 完了加重工数(i) / コミット加重工数(i)

Team PRR = 全メンバーのPRRの加重平均
  重み: 各メンバーのStrategic Weight合計

表示フォーマット:
  [創業者名]    PRR: XX% [▲/▼ 前週比]
  [メンバーB]   PRR: XX% [▲/▼ 前週比]
  [メンバーC]   PRR: XX% [▲/▼ 前週比]
  ─────────────────────────
  Team PRR:     XX%
```

### ボトルネック検知

```
以下のパターンを自動検知:

1. 依存ボトルネック
   「AのタスクがBの完了待ちで3日以上止まっている」
   → 「⚠️ [タスク名]が[名前B]のボトルネックです」

2. PRR格差
   最高PRRと最低PRRの差が25%以上
   → 「⚠️ チーム内のPRR格差が大きくなっています」

3. 特定メンバーへの集中
   1名のStrategic Weight合計がチーム全体の40%以上
   → 「⚠️ [名前]にタスクが集中しています。委譲を検討してください」

4. OKR未紐付けタスクの蓄積
   OKR-Unbound タスクが全体の30%以上
   → 「⚠️ OKRに紐付かないタスクが増えています」
```

### 週次チームレポート

毎週金曜に生成して Slack に通知（MCP接続時）：

```

メンバー別:
・[名前A]: XX% ✅
・[名前B]: XX% ⚠️ [理由]
・[名前C]: XX% ✅

今週のボトルネック:
[検知された問題]

来週のフォーカス:
[チーム全体で優先すること1つ]
```
