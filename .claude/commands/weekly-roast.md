# /weekly-roast — 週次PRR評価＋Gemini監査プロンプト生成

毎週金曜に実行します。今週の実行を誠実に評価し、Gemini向けの監査プロンプトを生成します。

## 実行手順

### Step 1: 今週のデータ収集
以下を確認してください（Notionとmemory/フォルダから）：

「今週（月曜〜今日）の状況を教えてください：
 1. 完了したタスクのリスト
 2. Delayedまたは未完了のタスクと理由
 3. 今週の顧客・投資家との接触回数
 4. 今週起きた重要な意思決定や発見」

### Step 2: PRRの計算
Notion Tasks DBのデータを参照して計算する（DB IDはcontext.md参照）：

```
PRR = 完了タスクの加重工数合計 / コミットした全タスクの加重工数合計

加重工数 = Est Hours × Strategic Weight × 誠実性係数
誠実性係数：Deadline Changes 0回→1.0、1回→0.7、2回→0.5、3回以上→0
```

PRRの判定：
- 90%以上：「約束が軽すぎます。もっと挑戦的な目標を設定してください」
- 70〜89%：「健全なゾーンです」＋改善点1点
- 60〜69%：「注意：コミット量を見直してください」
- 60%未満：「危険：今週のコミットを半分に減らすことを推奨します」

### Step 3: CLAUDE.mdのPRRセクションを更新
先週PRRと未達原因を更新することを提案する。

### Step 4: Gemini監査プロンプトの生成
以下のプロンプトを生成して出力する（コピペでGeminiに投入できる形式）：
